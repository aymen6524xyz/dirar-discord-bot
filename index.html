01 · Overview

Introduction

Colonel Hans is a multipurpose Discord bot built with Node.js and Discord.js. It can support community administration, verification alerts, moderation workflows, voice-channel monitoring, direct-message relay, and other server-configured commands.

This policy explains how the bot processes information when it is installed in or used on a Discord server. It applies to server members, visitors who interact with the bot, and server administrators who configure it. Discord also processes information under its own policies and terms.

02 · Data map

Information we process

The bot only receives information made available through Discord events and the permissions granted to it. Based on the current source code, the following categories are relevant:

Persisted in local JSON files

Discord user IDs associated with DM relay permissions, blacklist entries, configured administrators, and forwarded-message lookup mappings. Some entries also include a reason, expiration, or timestamp.

Processed temporarily

Message content for prefix commands, direct-message forwarding, reactions, and the automated slur filter. Voice-state changes, member/role context, and audit-log entries may be held in memory while alerts or abuse checks run.

Sent to Discord channels

When DM relay is enabled, the bot forwards a user's message, attachments, and stickers to a configured staff channel. A user ID is encoded into the forwarded message so authorised staff can reply.

Not intentionally collected

The source reviewed does not show a separate analytics database, advertising profile, website tracker, or a general-purpose archive of every message. The bot does not intentionally request passwords, payment details, or Discord tokens.

The bot can see usernames, display names, roles, channel IDs, server IDs, message IDs, and other Discord metadata when required by an event or command. It does not necessarily store each item permanently. Server administrators should review their enabled systems and Discord permissions.

The verification leaderboard command reads recent messages from one configured verification channel, identifies matching verification commands, and calculates a seven-day result in memory. The reviewed implementation does not save that leaderboard as a separate database record. Moderation and verification log commands instead publish embeds containing IDs, names, reasons, and timestamps to the Discord channel where they are used.

03 · Purpose

How we use information

  • To execute prefix and slash commands and enforce configured permission levels.
  • To operate server-specific DM relay, verification alerts, moderation notifications, and administrative automation.
  • To react to configured events, remove messages identified by the automated filter, and apply configured timeouts where the bot has permission.
  • To detect recent voice moderation changes and notify an authorised monitoring channel about possible abuse.
  • To troubleshoot failures using console diagnostics and error messages.

Server owners and authorised administrators decide which channels, roles, and features are configured. Colonel Hans is not a replacement for a server's own moderation judgment.

04 · Discord access

Message content and Discord permissions

Colonel Hans is configured with Discord's Message Content, Guild Messages, Direct Messages, Guilds, and Guild Voice States gateway intents. It processes message content to recognise prefix commands, handle permitted DM relay, react to configured IDs, and run the automated slur filter.

Ordinary message content is not written to the bot's local JSON data by the reviewed code. However, a permitted DM and its attachments can be forwarded into a Discord staff channel, where Discord and that server's administrators may retain it. The DM relay mapping stores the originating user ID and forwarded message ID with a timestamp.

Messages flagged by the slur filter are deleted when possible. The filter's per-user count exists in memory and is reset after 15 minutes; this is not a permanent moderation history in the reviewed code.

05 · Safeguards

Data storage and security

The reviewed project uses local JSON files rather than SQLite or another database. These files include configuration and bot operational data such as DM relay mappings, allowlists, blacklists, and administrator IDs. Some event trackers exist only in process memory. Console logs may contain operational errors and Discord identifiers depending on the event.

The source does not establish encryption at rest, a formal access-control program, backups, a security certification, or a guaranteed hosting environment. The operator is responsible for protecting the bot host, configuration files, environment variables, and Discord token. Never publish those secrets with this website.

06 · Lifecycle

Data retention

The only explicit retention rule found in the reviewed code is that DM relay lookup mappings older than seven days are pruned when new mappings are saved. In-memory slur-filter counters expire after 15 minutes, and verification alert messages are scheduled for deletion after 10 minutes when deletion succeeds.

Configured allowlists, blacklists, administrator IDs, and other JSON configuration entries do not have a general automatic retention period. [OWNER: define and document retention periods for these records, console logs, and any server-specific logs before publication.]

Removing the bot from a server does not, based on the reviewed code, automatically erase local JSON records. A deletion request may be needed separately.

07 · Disclosure

Sharing and disclosure

Colonel Hans relies on Discord's API and infrastructure to receive events and send responses. Information can therefore be transmitted to Discord and displayed to members or staff in the channels where the bot operates. The DM relay feature specifically sends permitted messages and attachments to its configured Discord staff channel.

No separate analytics, advertising, or external data-broker integration was identified in the reviewed source. 09 · Age

Children's privacy

Colonel Hans is intended to operate within Discord communities and Discord's applicable age requirements. The operator does not knowingly seek information from children outside those requirements. If you believe information has been processed in a way that raises a children's privacy concern, contact the operator promptly. The operator should obtain legal advice about any obligations that apply in the countries where the bot is offered.
